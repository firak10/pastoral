Fluxo de Gravação:
  1. Coloque as URLs, uma por linha.
  2. Gere os comandos.
  3. Para uma MIFARE Classic nova, formate como NDEF quando necessário: hf mf ndefformat.
  4. Execute o comando gerado.
  5. Verifique com hf mf ndefread.

🔒 O gerador funciona localmente no navegador; não envia as URLs para a internet.
